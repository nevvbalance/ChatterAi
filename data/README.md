# База русских пословиц ChatterAi

Здесь хранится корпус народной мудрости, который используется для смыслового поиска и формирования ответов бота.

## Файлы

- `russian_proverbs.json` — основная база с семантической разметкой.
- `russian_proverbs_candidates_001.json` — первая кандидатная партия.
- `russian_proverbs_candidates_002.json` — вторая кандидатная партия.
- `dataset_plan.md` — правила и план развития корпуса.

## Принцип

Кандидатные записи сначала проверяются и только затем попадают в основную базу. Это позволяет сохранять качество, избегать дублей и отдельно хранить историческую формулировку, современное толкование и семантические признаки.

## Следующий этап

После накопления нескольких сотен проверенных записей подключить семантический поиск к `bot.py`, чтобы пользовательский вопрос сопоставлялся с ситуациями, темами и смыслом пословиц, а не только с точным совпадением слов.
