# Датасет русских пословиц ChatterAi

## Цель

Построить постоянно расширяемую базу русских пословиц и поговорок для смыслового поиска. Бот должен подбирать пословицы по ситуации пользователя, а затем формировать ответ с явным указанием использованных пословиц.

## Источник корпуса

Основной исторический корпус: В. И. Даль, «Пословицы русского народа», 1862. На Викитеке доступны тематические разделы полного корпуса. Источник: https://ru.wikisource.org/wiki/Пословицы_русского_народа_(Даль)

## Правила наполнения

1. Не считать каждую строку автоматически пословицей. Сохранять тип: `пословица`, `поговорка`, `речение`, `присловье` и т. п.
2. Не смешивать несколько вариантов одной единицы в отдельные записи без необходимости.
3. Сохранять варианты в поле `variants`.
4. Для каждой записи добавлять современное краткое толкование в `meaning`.
5. Добавлять 2–6 тем, 2–6 типичных ситуаций и 3–10 ключевых понятий.
6. Исторический текст и современное толкование хранить раздельно.
7. Не приписывать Далю современные толкования.
8. Проверять дубли и почти-дубли перед добавлением.
9. Сохранять источник и год издания.
10. Расширять базу партиями, после каждой партии проверять JSON на валидность.

## Целевая структура записи

```json
{
  "id": "rp-XXXX",
  "proverb": "...",
  "type": "пословица",
  "meaning": "...",
  "topics": ["..."],
  "situations": ["..."],
  "keywords": ["..."],
  "variants": [],
  "source": "Даль, 1862"
}
```

## Этапы

- v1: первые 20 записей, проверка схемы.
- v2: массовое добавление корпуса Даля тематическими разделами.
- v3: дедупликация, нормализация орфографии и вариантов.
- v4: расширение семантической разметки.
- v5: подключение смыслового поиска к Telegram-боту.
- Далее: постоянное пополнение новыми проверенными источниками.
